# agentme-core ADRs Index

Meta-governance architectural decisions for the `agentme` scope.

## Principles

Foundational standards, identity, and authoring conventions for the agentme scope.

- [agentme-core-adr-001](principles/001-core.md) - **agentme scope identity and content standards** - Defines the agentme scope's audience, purpose, distribution model, and writing standards for all its XDRs and skills
- [agentme-core-adr-002](principles/002-policy-numbering.md) - **agentme policy numbering** - Specializes the xdrs-core numbering standard for agentme EDR application policies: topic-group blocks within the 101–200 range (101–120 language, 121–140 architecture, 141–150 AI development, 151–160 AI evaluation, 161–200 unreserved)
- [agentme-core-adr-003](principles/003-skill-numbering-ranges.md) - **agentme skill numbering ranges** - Global semantic skill numbering scheme ordered by increasing complexity/risk; human and agentic skills share ranges (1–49 meta, 50–99 engineering, 100–149 local data, 150–199 operational/business procedures, 200–249 testing/QA, 250–299 connectors, 300–349 read single, 350–399 read multi, 400–449 HITL write single, 450–499 HITL write multi, 500–549 autonomous write single, 550–599 autonomous write multi, 600–649 orchestrations, 900+ overflow)
