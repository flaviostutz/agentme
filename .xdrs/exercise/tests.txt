Intake profile 
Create a profile called “Intake” that will be used to give initial guidance on which detailed profiles the user could explore further. This is a special profile that has one characteristic per other profiles and each of these characteristics either reuse an existing question that represents well the profile being tested, or we need to create a special question for it (that might be more generic than the normal ones so it can span more the exploration). This is a new type of question: “bootstrap”. The Intake profile must be kept up to date everytime a new profile is created (so it gets a new characteristic that represents that profile with questions). The intake profile must: have 2-4 questions per characteristic (that represents another profile) being explored, and its questions must try to detect things that are a high indicative that a certain profile should be explored. It means that those questions doesn’t need to be too broad or generic, but must focus on specific things that are sensors about a possible match to one or other profile, trying to make it a discriminating question between profiles, but that at the same time will reduce false negatives (in case the person has a certain profile but the question is too specific to something they don’t have). Try to find the good set of questions that can guide flags about a certain profile. This Intake profile must be up to date whatever we change the question bank to represent the different profiles that can be assessed along with the type of questions/content that it has. At the end of answering this special intake profile we should be able to score all the other profiles and check which ones deserves to continue to be investigated with all its questions then (we will activate this profile in current session then for further exploration reusing the same questions that were already answered, but this is outside this scope).

Scientific link to questions
Improve the link of our questions to the scientific instruments link it might be connected to
  - create a catalog of instruments and its questions
  - make clear links in the questions to one or more questions in a instrument, with source types “copy-from”, “adapted-from”, “inspired-on”. Adapted-from: means the content is very similar, but with different wording or phrasing, not changing the main idea; inspired on: the content might be different, also combining with other questions, but the concepts and content doesn’t conflict or go against the original content; copy-from: this is a copy of the original question text. Attributes in question are sources: [{instrumentId, instrumentQuestionId, sourceType}]
  - with this link it should be possible to create a “scientific” score for a certain group of questions (involved in an profile or any other cut) about how much they are tight to scientific instruments. The instrument catalog should also have a methodologyAlignmentScore (0.0-1.0) about how well the instrument methodology is aligned with our engine and that influences the overall scientific score for the questions
  - scientific instrument -> instrument question N-[source]-N bank question
  - bank questions must have a scientific references text field that can also be used when there is no specific instrument question connected, but the question was based on an article or scientific paper. The reference must indicate the bibliographical ref along with the chapter or summary of the concept in the paper.
